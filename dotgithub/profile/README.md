**Square Hole** is a place for NFT collections on Ethereum. Every collection sits in its own box, an on-chain vault,
with one token for the whole box: you can swap that token for an NFT from the box, and put an NFT back for the token.
Every box works the same way, whatever shape its contents take. FIT is the first token. Square Hole is in
development; nothing here is an offer or advice.

[squarehole.fun](https://squarehole.fun) · [squarehole.xyz](https://squarehole.xyz) · [squarehole.fit](https://squarehole.fit)

Logos, colours and the brand guide are in the **branding** repository.
