# Colours

Square Hole is a dark brand: a navy canvas, a lavender hole that glows, and white text. `tokens.json` is the source.
`tokens.css` is generated from it, and the table below is computed from it (WCAG 2.x formula).

| Role | Name | Hex | Token |
|---|---|---|---|
| Brand colour | Lavender | `#A78BFA` | `--sh-accent` |
| Button fill | Violet | `#6D4AE2` | `--sh-action` |
| Base | Navy | `#080D16` | `--sh-canvas` |
| Cards | | `#111B29` | `--sh-surface` |
| Raised | | `#18253A` | `--sh-surface-raised` |
| Text | | `#F3F5FB` | `--sh-text` |
| Secondary text | | `#B5C0D5` | `--sh-text-secondary` |
| Glow (decoration) | Glow | `#C4B2FF` | `--sh-brand-glow` |

The `--sh-*` names are the same as in the Square Hole app, so `tokens.css` drops into the app or any page styled like
it. `node scripts/tokens.mjs --check` also confirms that every shared colour still equals the app's value.

## Rules that follow from the numbers

- **Lavender is the brand.** Use it for the hole, links, labels and focus rings on dark surfaces.
- **Violet is a fill, not a text colour on dark.** Put white text on it. On dark surfaces it is too low for text and
  must never be the only colour of a mark.
- **On white,** use the full-colour mark, the navy mono mark or navy text. Lavender on white is too light for text or
  for the flat mark. Violet text on white is fine.
- **Glow and the neon core are decoration.** Never set text in them.
- **Positive, negative and warning are UI states,** always shown with a sign or arrow. Keep them out of brand art and
  never put them around the mark: a green or red glow means nothing about money.
- **The tile is quiet on purpose.** On the navy canvas the tile barely separates from the page; the lavender lip and
  the lit rim carry the shape. Do not add an outline or drop shadow to make it louder.

## Contrast

"Needs" follows WCAG 2.2 AA: 4.5 for body text, 3 for large text and for non-text shapes such as icons and control
edges. "avoid" rows document pairs that must not be used.
